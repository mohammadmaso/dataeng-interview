## به زبان ساده (مبتدی)
فرض کنید در پایان کلاس برگه‌های امتحان را جمع می‌کنید. نمی‌شود تا ابد منتظر دانش‌آموزی ماند که شاید هنوز می‌نویسد؛ پس می‌گویید «تا ۱۰ دقیقه بعد از زنگ قبول است، بعد از آن پوشه را می‌بندم.» واترمارک همین قاعده برای استریم است. رویدادها ممکن است دیر و نامرتب برسند و واترمارک مشخص می‌کند سیستم چقدر صبر کند تا یک پنجره‌ی زمانی را تمام‌شده اعلام کند.

## نحوه‌ی کار (متوسط)
استریم دو ساعت دارد: event time (زمان وقوع) و processing time (زمانی که سیستم دیده). واترمارک `W(t)` یک ادعای تخمینی است: «فرض می‌کنیم همه‌ی رویدادهای با event time کمتر یا مساوی W رسیده‌اند.» معمولاً `W = بیشینه‌ی event time دیده‌شده - تأخیر مجاز`.

وقتی واترمارک از انتهای یک پنجره رد شود، موتور نتیجه را منتشر می‌کند و state آن پنجره را پاک می‌کند. رویدادهایی که پشت واترمارک برسند «دیر» هستند: دور ریخته می‌شوند، به side output می‌روند، یا اگر allowed lateness تنظیم شده باشد پنجره را به‌روز می‌کنند.

```
// Flink: tolerate events up to 10 s out of order
WatermarkStrategy
  .<Event>forBoundedOutOfOrderness(Duration.ofSeconds(10))
  .withTimestampAssigner((e, ts) -> e.eventTimeMs);

// Spark Structured Streaming
df.withWatermark("event_time", "10 minutes")
  .groupBy(window("event_time", "5 minutes")).count()
```

وقتی چند پارتیشن یا ورودی داریم، واترمارک عملگر کمینه‌ی آن‌هاست؛ پس یک پارتیشن بیکار می‌تواند کل جریان را متوقف کند مگر idleness detection فعال باشد.

## نگاه سنیور و نکات مصاحبه
واترمارک مصالحه‌ی تأخیر و کامل‌بودن است: تأخیر کم یعنی نتیجه‌ی سریع ولی ناقص؛ تأخیر زیاد یعنی نتیجه‌ی کامل‌تر با latency و state بیشتر. واترمارک heuristic است نه تضمین؛ پس سیاست داده‌ی دیررس یک تصمیم محصولی است. حالت‌های خرابی: واترمارک متوقف‌شده به‌خاطر پارتیشن Kafka بیکار، ساعت خراب یک producer که واترمارک را بسیار جلو می‌برد (و بقیه «دیر» حساب می‌شوند)، و state بی‌کران وقتی واترمارک جلو نمی‌رود. در Spark واترمارک state تجمیع و dedup استریمی را هم محدود می‌کند.

سؤال مصاحبه: «رویداد دیررس چه می‌شود؟» پاسخ: اگر پنجره‌اش نسبت به واترمارک بسته شده باشد حذف یا به side output می‌رود؛ بسته به دقت لازم، allowed lateness یا اصلاح دوره‌ای batch را انتخاب می‌کنم.
